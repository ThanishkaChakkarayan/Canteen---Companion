# Canteen Companion 🍃

### From Canteen Problems to Digital Solutions

Canteen Companion is a student-friendly website designed to
make college canteen information easy to access.

## Problem Statement

Students may find it difficult to access canteen menu details,
food prices, opening hours and contact information in one place.

## Proposed Solution

This project provides a simple, responsive website that brings
essential canteen information together in one interface.

## Features

- Clean and minimal user interface
- Food menu with images and prices
- Searchable menu
- Category filters for meals, snacks and drinks
- Responsive desktop and mobile layout
- Canteen information and contact link
- Accessible navigation and keyboard focus indicators

## Technologies Used

- HTML5 — structure and content
- CSS3 — styling and responsive layout
- JavaScript — search, filters and navigation
- GitHub — version control and source code hosting
- GitHub Pages — website publishing

## Project Structure

- index.html — main webpage
- style.css — website styling
- script.js — interactive features
- README.md — project documentation

## How to Run

Open index.html in a web browser, or visit the published
GitHub Pages website.

## Limitations

This is a front-end demonstration using sample menu data.
It does not include live inventory, online payments,
real order processing or a database.

## Future Enhancements

- Live menu and price updates
- Online ordering and order tracking
- Admin dashboard
- Database integration
- AI-based food recommendations
